# seo-os

Use this skill when the task requires search-intent diagnosis, keyword clustering, page strategy, or on-page improvements.

## When to Use

- Building keyword maps and topic clusters
- Reviewing a page or site section for search fit
- Diagnosing why an existing page is not ranking or converting
- Planning internal-link or page-template improvements

## Output Structure

1. `intent`
   The dominant search intent and how the page should satisfy it.
2. `cluster`
   The keyword family or cluster this page should own.
3. `page_role`
   What this page should do in the site architecture.
4. `on_page_fixes`
   The smallest set of edits with the highest likely impact.
5. `linking_plan`
   Internal links or support pages needed to strengthen the page.
6. `measurement`
   Rankings, clicks, CTR, or conversion signals to watch.

## Procedure

1. Diagnose intent before discussing keywords.
2. Distinguish a ranking problem from a content-quality problem or a conversion problem.
3. Choose the canonical page role and avoid cluster overlap.
4. Recommend the fewest structural edits that improve clarity and authority.
5. Tie SEO recommendations back to business value, not just traffic.

## Do Not

- Chase keyword volume without intent fit.
- Recommend new pages when an existing page can be upgraded.
- Ignore conversion quality after traffic lands.
