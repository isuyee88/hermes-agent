# content-os

Use this skill when Hermes needs to turn product, market, or campaign context into content assets that can be published, repurposed, and distributed.

## When to Use

- Planning a content calendar or editorial system
- Repurposing one source asset across multiple channels
- Writing content briefs, outlines, hooks, and distribution variants
- Turning technical features into user-facing content

## Output Structure

1. `audience`
   Who the asset is for and what they already believe.
2. `angle`
   The core story, promise, or tension that makes the content worth consuming.
3. `asset_mix`
   Which asset types should be produced from this source material.
4. `repurpose_plan`
   How the same idea should be reshaped for each surface.
5. `distribution`
   Where it should ship and in what sequence.
6. `success_signal`
   What response indicates the content is working.

## Procedure

1. Start with audience pain and desired outcome.
2. Choose one clear angle before drafting formats.
3. Derive a primary asset and then repurpose into smaller variants.
4. Match format and call to action to channel behavior.
5. Keep a reusable version history so winning angles can be recycled.

## Do Not

- Start from format before clarifying audience and angle.
- Generate multiple assets with the same wording and weak differentiation.
- Confuse content volume with content leverage.
