# affiliate-os

Use this skill when the work spans multiple affiliate functions at once: traffic, content, offers, partners, payout quality, retention, and operating cadence.

## When to Use

- Weekly operating reviews for an affiliate startup
- Prioritizing channels, offers, or partnerships
- Diagnosing why traffic is not converting into revenue
- Aligning growth, BD, finance, and operations around one plan

## Output Structure

1. `revenue_model`
   Current monetization path, payout logic, and the core value exchange.
2. `growth_levers`
   The highest-leverage channels, offers, or execution loops.
3. `constraint`
   The main bottleneck blocking growth or profitability right now.
4. `operator_plan`
   What content, growth, BD, ops, finance, and tech should each do next.
5. `metrics`
   The smallest set of numbers that will validate progress.
6. `risks`
   What could waste spend, slow payout, or create fragile growth.

## Procedure

1. Clarify the current traffic, conversion, payout, and retention loop.
2. Separate signal from activity: what is truly working versus just consuming effort.
3. Identify the primary bottleneck before proposing parallel initiatives.
4. Translate strategy into role-based actions with owners and cadence.
5. Tie every recommendation back to margin, payout quality, or learning velocity.

## Do Not

- Treat more traffic as the default answer before checking conversion and payout quality.
- Mix channel experimentation with core operating fixes in one vague plan.
- Recommend broad expansion without clear ROI logic.

## Collaboration

- Pair with `growth-os` for channel and conversion work.
- Pair with `bd-os` for partner strategy and outreach.
- Pair with `finance-os` for profitability, payout, and budget review.
- Pair with `ops-os` when the problem is execution drag rather than strategy.
- Pair with `browser-ops` when recommendations depend on what is true on live pages, offers, or partner sites.
- Pair with `automation-os` when recurring checks or monitoring should become repeatable execution loops.
